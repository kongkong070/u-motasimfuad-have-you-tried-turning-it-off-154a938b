One funny single-line reply from a hopeless tech support agent to a desperate customer, written by `main.ts` into `/output/entry.txt`:

> Have you tried turning it off and on again — and this time, have you tried apologising to it first?

The program validates the entry against the gate (UTF-8 text, 1–199 characters, not only whitespace, a single line) and writes it deterministically — the same bytes on every run.

## Run

```sh
npx tsx main.ts
# or: node --experimental-strip-types main.ts
```

`MAKEFUN_OUTPUT_DIR` sets the output directory (default `/output`).
